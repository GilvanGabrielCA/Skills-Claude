# Estilo das frases e comentários (BoosterFace)

Banco de estilo para os textos que vão na tela. Tudo em **inglês americano**. A regra de ouro: **o texto cita a
virada visível do clip** (nunca genérico). Leia a `SKILL.md` para o processo (4 fps + comentários + SETUP→VIRADA).

## Frases que funcionaram (dos vídeos campeões, 15–39M views)
- Relatable / "me:": `what did you do for new years?`, `Money hungry`, `Friendly fire`
- POV: `POV: you live in End Rod civilization`
- Reação curta: `bro tf??`, `What?????`, `I'm uninstalling`
- Expectativa × realidade (duas linhas, uma em cima do clip, outra embaixo): `bro: the xp farm is done` / `the xp farm:`
- "Novo recurso" falso: `New ARG just dropped`, `A-Train mod`, `Wind burst lvl 1000`
- Descrição com humor: `Skinwalker dog`, `Poor skeleton`, `Minecraft bugdrock`, `64 diamonds ❌ 8 diamonds ✅`
- IRL / sincronizado: `Minecraft IRL`, `The Log IRL`, `Why does this sync so well??`

## Formatos de frase (escolha pelo que o clip mostra)
| Formato | Quando usar | Exemplo |
|---|---|---|
| `POV: …` | o espectador "é" o personagem da cena | `POV: you spawned next to the Warden` |
| `Me when …` / `me:` | reação relatable a algo comum | `me after one (1) creeper` |
| Pergunta relatable | gancho que faz ler | `what did you do for new years?` |
| Reação curta | virada absurda | `bro tf??`, `no way bro` |
| Expectativa × realidade | o que era pra ser vs o que foi | `the xp farm:` |
| "Novo X / lvl 1000" | exagero de um recurso | `Wind burst lvl 1000` |
| `… IRL` / sync | vídeo real casado com o jogo | `Minecraft IRL` |

## Comentários — tom e exemplos
- Tom meme/Gen-Z: `bro`, `lowkey`, `no way`, `dawg`, `fr`, `any%`, `he did NOT…`. **Comenta a virada**, não descreve.
- Até 2 linhas curtas (~24 caracteres cada), quebra com `/`.
- Exemplos (ligados a uma virada):
  - susto do Warden → `The Warden heard him / from 3 biomes away`
  - morреu numa queda boba → `Bro speedran the / death screen any%`
  - cachorro bugou no teto → `dog unlocked / creative mode`
  - fogos sozinho na caverna → `celebrating with the / cave bats fr`

## Faça / Não faça
- **Faça:** citar o objeto/mob/mensagem da virada; manter curto; piada que qualquer jogador entende; variar o
  formato entre os 5 (não 5 "POV:" seguidos).
- **Não faça:** texto genérico ("so funny", "crazy moment"); descrever o óbvio; inventar piada quando a virada é
  só áudio (pergunte); duplo sentido sexual; copiar comentário de outra pessoa do post.

## Emoji (atenção à fonte)
Os campeões usam emoji nas frases (😭 😏 🤑 👀). Use **no máximo 1**, e só se o editor do usuário desenhar emoji na
fonte do vídeo. Sempre tenha uma versão **sem emoji** pronta — se a fonte não desenhar, o usuário avisa e você troca.
